Voici les commandes **`curl`** utiles.

### 1) Vérifier le code (étape principale)

```bash
curl -sk -X POST 'https://pbx.local/provision/api/v1/verify.php' \
  -H 'Content-Type: application/json' \
  -d '{"email":"adengioce@gmail.com","code":"123456"}'
```

Remplace **`123456`** par le **code à 6 chiffres** reçu par e-mail.

---

### 2) Si tu n’as pas encore de code (relancer l’inscription)

```bash
curl -sk -X POST 'https://pbx.local/provision/api/v1/register.php' \
  -H 'Content-Type: application/json' \
  -d '{"email":"adengioce@gmail.com"}'
```

Puis refais l’étape 1 avec le nouveau code.

---

### 3) Vérifier l’état après coup

```bash
curl -sk 'https://pbx.local/provision/api/v1/status.php?email=adengioce@gmail.com'
```

**Note :** `-k` ignore l’erreur de certificat TLS si ton certificat n’est pas reconnu pour `pbx.local`.

La commande corrigée (utilisateur FreePBX **`asteriskuser`**, base **`asterisk`**) :

```bash
mysql -u asteriskuser -p1234 asterisk -e "UPDATE provision_requests SET email_verified=0, status='pending', extension=NULL, verify_code_hash=NULL, verify_expires=NULL, updated_at=NOW() WHERE email='adengioce@gmail.com';"
```
Detele access
mysql -u asteriskuser -p1234 asterisk -e "DELETE FROM provision_requests WHERE email = 'adengioce@gmail.com';"
mysql -u asteriskuser -p1234 asterisk -e "DELETE FROM provision_tokens WHERE email = 'adengioce@gmail.com';"

Pour vérifier après :

```bash
mysql -u asteriskuser -p1234 asterisk -e "SELECT email, status, email_verified, extension FROM provision_requests WHERE email='adengioce@gmail.com';"
```

**Note :** `sudo mysql` sans `-u`/`-p` tente `root` sans mot de passe → erreur **1045**. Ici il faut **`asteriskuser`**, pas `root`.

Si tu préfères saisir le mot de passe sans l’afficher :

```bash
mysql -u asteriskuser -p asterisk -e "UPDATE provision_requests SET email_verified=0, status='pending', extension=NULL, verify_code_hash=NULL, verify_expires=NULL, updated_at=NOW() WHERE email='adengioce@gmail.com';"
```

(puis tape **`1234`** quand il le demande)
